Автозапуск теперь включает обход, а не только открывает окно.

- Задача в планировщике создаётся с правами администратора: без них драйвер не загружался и компоненты при старте системы не поднимались
- Задачи, созданные прошлыми версиями, пересоздаются автоматически при первом запуске
- При первом запуске приложение предлагает включить автозапуск вместе с обходом. Предложение появляется и у тех, у кого запуск с Windows уже был включён
- Исправлено зацикливание окна обновления: после установки оно предлагало обновиться снова
- Папка внутри портативного архива называется ZapretEra
