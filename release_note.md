Исправлен TG WS Proxy, который переставал запускаться после обновления из приложения. Внутри свежий tg-ws-proxy 1.11.1.

- Если обновить TG WS Proxy через менеджер обновлений, прокси больше не запускался и показывал «TG WS Proxy worker did not open listening port. (exit code: 3)». Новым версиям tg-ws-proxy нужны библиотеки для HTTP/2, которых в приложении не было. Теперь они встроены
- Приложение больше не установит версию TG WS Proxy, которая не сможет запуститься. Вместо этого оно попросит обновить само приложение, а рабочий прокси останется на месте
- Если прокси всё-таки не стартует, в окне ошибки теперь виден настоящий текст ошибки, а не одна общая фраза
- TG WS Proxy обновлён до 1.11.1: загрузка медиа и файлов через CF-прокси идёт одним потоком по HTTP/2, из-за чего стандартные CF-домены доступны чаще. Прямое подключение к DC по IP теперь работает только при размере пула WebSocket-сессий больше 0 (по умолчанию 4)
